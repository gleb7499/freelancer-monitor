# Правила отбора заказов — универсальная рамка

> Дата: 2026-10-04 (переписано после чистки легаси: канал один — Freelancer.com,
> search-линия и Upwork-файлы удалены).
> Операционный источник правил для работающего конвейера —
> [freelancer-правила-отбора.md](freelancer-правила-отбора.md) (его текст уходит
> в системный промпт LLM). Этот файл — рамка принципов, общих для любой площадки,
> если площадок станет несколько.
> Ниши: см. [freelancer-список-ниш.md](freelancer-список-ниш.md).

## Принципы

| Правило | Значение |
| --- | --- |
| Оплата клиента | верифицирована — плюс; нет верификации/депозита — фактор риска, взвешивает LLM (авто-BID и авто-PASS запрещены) |
| Отклики у заказа | чем меньше, тем лучше; конкуренцию режет кодовый гейт до LLM |
| Явный фуллтайм | пас |
| Возраст заказа | только свежая выдача |
| Язык заказа | английский — ок, остальные — пас |
| Бесплатные тесты | запрещены |
| Объём-ловушка | дёшево ≠ мелко; считаем часы. Не исключаем объёмные заказы только из-за цены — решает value-score |
| Senior-опыт / узкий домен без нашего опыта | пас |
| Чистый дизайн без кода (UI/UX, «design only») | пас — это заказы для дизайнеров |
| Мобильная разработка (React Native / Flutter / native) | пас — не профиль |
| Дедлайн короче 7 дней при объёме более 30 ч | брать только с оговоркой «+дни до контракта» |
| Оценка времени | оптимистичный / реалистичный / пессимистичный — всегда тремя числами |

## Ставка (синхронизировано с freelancer-правила-отбора.md)

- Сумму ставки устанавливает **код** детерминированной формулой стратегии
  первых отзывов: `min(низ вилки; средняя конкурентная ставка × 0.65)`, в валюте
  заказа, круглая сетка; нет ставок — низ вилки (fixed и hourly одинаково).
  Пол «70% середины» отменён: платформа сама не даёт ставку ниже низа вилки.
- Низкая цена — осознанная стратегия набора первых отзывов: в тексте отклика
  она объясняется новизной платформы и целью получить первый отзыв, а не
  «скидкой от обычной ставки».

## Этапные платежи (milestones)

- Этапы — всегда, на любом fixed-заказе: первый этап 30% (зашит в ставку),
  далее по размеру заказа до 4 этапов (30/70, 30/30/40, 30/30/30/10).
  Релиз этапа — только по факту готовности (досрочный релиз + жалоба = штраф
  ранга); отзывы возможны только при полной оплате через milestone-систему.

Платформенная механика (API, гейты, апгрейды, комиссии) — только в файле
платформы: [freelancer-правила-отбора.md](freelancer-правила-отбора.md).
